Escape the Four Rooms

You wake up locked inside a strange old house. Search every room, collect items, crack the codes and solve the riddles. Four rooms stand between you and freedom. Can you get out?

About Us

Four Doors is a small browser puzzle game built with plain HTML, CSS and JavaScript. No downloads, no sign-up: open the page and start escaping. Every room is a chain of clues, so look closely and think about how the objects connect.

4 RoomsLibrary, Clock Room, Dark Cellar and the Final Vault.
Varied PuzzlesRiddles, ciphers, color orders, item use and a dial lock.
HintsStuck? Each room has three hints. Fewer hints earn more stars.
⏱Beat the ClockYour time is tracked, so try to improve your best run.
